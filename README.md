O Problema?
A invisibilidade dos moradores de comunidades do Recife para a solução de seus problemas.
O Público?
Moradores das comunidades periféricas do Recife.
Uma solução?
Uma aplicação web e mobile (principalmente mobile) que tem como objetivo principal ser um canal de denúncias e comunicação entre os moradores e líderes comunitários (ou associações de moradores), para que as denúncias sejam realmente ouvidas pelas autoridades competentes.# Grupo3_PoF
